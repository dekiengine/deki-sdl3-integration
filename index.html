SDL3 display, input, and filesystem integration

Repository: github.com/dekiengine/deki-sdl3-integration · Latest release: 0.15.0 · Needs engine 0.15.0+ · Requires: deki-input

Install with DekiEditor --packages-add deki-sdl3-integration <project>, or from the Package Manager. The engine's own components and C++ API are in the Deki docs.
